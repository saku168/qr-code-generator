# QR Code Generator

A small QR code generator interface built with **HTML, CSS and vanilla JavaScript**.

## Features
- Enter text or a URL.
- Generate a QR code image.
- Simple responsive interface.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Make sure you have an internet connection when generating a QR code.

## External service
QR generation uses the public QR Server API. The text or URL entered is sent to that service to create the QR image, so avoid entering private or sensitive information.

## Files
- `index.html` — generator interface
- `style.css` — styling
- `script.js` — QR request and display

## What this project practises
Reading user input, building a URL, and displaying an image returned by an external service.
